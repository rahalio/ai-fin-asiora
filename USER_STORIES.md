# Asiora — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Group strategy lead

- As a group strategist, I want insurance, AM, RE, and AI bets on one board, so that we stop double-funding the same customer journey.
- As a group strategist, I want unpostured insurance projects flagged, so that teams cannot hide behind generic “digital.”

### Insurance transformation lead

- As an insurance lead, I want to fund experiments against an explicit future scenario, so that channel bets are not confused with machine-UW bets.
- As an insurance lead, I want ethics flags on genomics/wellness data uses, so that conduct risk is visible early.

### Asset management COO

- As an AM COO, I want M&A diligence and integration checklists enforced, so that we do not repeat the failure modes Deloitte’s survey highlights.
- As an AM COO, I want operating-model components (data, process, talent, controls) scored for each transformation item, so that “agile” is not a slogan.

### Real estate services lead

- As a RE services lead, I want data plays to declare localisation and consent basis by market, so that “data is the new gold” does not become regulatory lead.
- As a RE services lead, I want monetisation hypotheses tied to group cross-sell only when allowed, so that property data is not silently siphoned.

### Data alliance / AI lead

- As an alliance lead, I want hub-vs-periphery scoring on data partnerships, so that we avoid becoming interchangeable capital.
- As an AI lead, I want talent gates on transformative bets, so that tools are not bought ahead of people.

### Board strategy committee

- As a board member, I want a SEA multi-vertical heatmap with kill/scale decisions, so that festival noise becomes governance.
